### 🔹 **Plataforma E-commerce Handmade – Angular + Spring Boot (en desarrollo)**  

Proyecto Full Stack desarrollado como parte de mi portfolio con el objetivo de diseñar una plataforma e-commerce para productos artesanales.

El proyecto está dividido en dos aplicaciones independientes (frontend y backend) comunicadas mediante una API REST e implementa autenticación mediante JWT, control de acceso por roles y una arquitectura desacoplada.

✔ Frontend desarrollado con Angular y Tailwind CSS, enfocado a una experiencia de compra visual y responsive.  
✔ Backend desarrollado con Spring Boot y arquitectura hexagonal.  
✔ Autenticación y autorización mediante Spring Security y JWT.
✔ Base de datos relacional con PostgreSQL.

🔗 Repositorio/documentación del proyecto: https://github.com/manuela217/handmade-shop
